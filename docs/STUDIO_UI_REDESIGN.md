# Harness Studio 界面优化

日期：2026-10-15。参考用户提供的“Harness Studio 中文任务运行界面”，保留原生前端、FastAPI 单体架构和既有 API。

## 页面结构

- 顶部品牌栏；第一版不增加侧边导航、账户设置或未实现的控制项。
- 左侧任务配置与最近任务，保留历史运行选择及模拟审批入口。
- 中间为回答内容、生成文件、执行轨迹、工具调用、项目上下文五个标签页，内容区域独立滚动。
- 右侧为运行概览、计划进度和深色日志窗口。状态仍准确显示未验证、预算耗尽等，不将模型结束包装为检查成功。
- 桌面采用视窗内工作区，键盘焦点不会把整页顶出视窗；窄屏改为纵向布局，短视窗使用紧凑概览。长路径省略显示，悬停可查看完整值，原始配置在上下文页保留。

## 独立日志窗口

日志窗口有明确高度范围和内部滚动，不随事件数量撑长整页。控制台显示时间、级别与简短事件说明；完整参数和结果在执行轨迹/工具调用标签页展开查看。

- 支持跟随最新事件；手动向上滚动后停止跟随。
- Home 跳到窗口顶部并暂停跟随；End 跳到底部并恢复跟随。
- “清空显示”只清空控制台视图，保留详细轨迹、游标和磁盘记录；刷新后可恢复。
- 日志、轨迹及工具详情各最多保留最近 300 个页面节点；总事件数量继续显示，完整记录留在 events.jsonl。
- 同序号事件不重复插入。切换记录和刷新沿用原有 GET 恢复流程，不重新提交任务。

## 回答排版

支持受限的 Markdown 标题、加粗、列表、表格、引用、行内代码和代码块，使用 DOM 元素与文本节点构建。原始 HTML、脚本、图片和链接不作为可执行页面内容解析，不使用外部 CDN 或新增前端依赖。提供复制原始回答按钮。轮询不会重复重建同一回答，阅读位置得以保留。
