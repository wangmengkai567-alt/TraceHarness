# 阶段七验收：联网搜索与网页正文读取

日期：2026-10-16。功能范围以 [分阶段实现计划](../HARNESS_MVP_IMPLEMENTATION_PLAN.md) 第九节为准，参数和边界见 [阶段七设计](STAGE_SEVEN_DESIGN.md)。

## 交付能力

- CLI 与 Web 共用 `web_search` 和 `read_webpage`；Tavily Search 找到来源，Extract 提取公开网页正文。无需安装额外运行依赖。
- 指定网址可直接读取；长文保存为运行内文档，通过文档编号与字符偏移续读，避免每段重新抓取。合并已读区间，跳读到末尾不等于读完全文。
- 来源清单、正文、实际返回范围、SHA256、抓取时间和实际请求次数落盘，来源索引独立于近期对话裁剪。最终结果记录引用编号存在性检查。
- 具备联网开关、密钥不可用提示、搜索与提取独立预算、限流及临时错误重试、响应与存储上限、取消和总时限；重试占实际外部请求次数。
- 工作台展示查询、读取网址、耗时、错误、可点击来源、时间、保存长度及已读范围；刷新只恢复记录。未变化的来源卡片不会被轮询重建。

## 浏览器检查与边界

在本次拥有的测试服务上使用真实浏览器打开已完成任务，核对回答表格、未验证状态、工具调用页签、可点击来源、提取时间、保存长度、读取区间和完整性状态。检查发现并修复来源卡片被普通轮询重建的问题，页面脚本回归包含保持卡片节点的检查。浏览器没有触发新的模型任务或额外搜索，临时页面已关闭。

联网默认关闭；操作者在启动 JSON 中设置 `network_enabled=true` 并提供 `TAVILY_API_KEY` 后启用，搜索词与待读网址会发送给 Tavily。公开网页提取不保证所有网站可访问或原文完整；登录、验证码、交互页面及 PDF 不在保证范围内。Tavily 执行实际抓取与重定向，本地 URL/DNS 预检不能替代第三方连接路径的隔离保证。

一轮全量回归曾在原有 Web 测试的 3 秒等待上限处超时。去掉联网关闭时不必要的来源文件写入后，该用例与阶段七检查一起通过，随后单独全量重跑 130 项通过；没有放宽原有等待上限或生产运行时限。

本次代码、测试、文档、配置和验收输出保持 UTF-8 无 BOM、LF，详见 [文件审计](stage-seven-file-audit.json)；未改动全局 Git 配置、暂存区或用户既有服务。
