# 阶段七设计：联网搜索与网页正文读取

日期：2026-10-16

## 范围与选型

保持 Python 后端同时提供页面与 API 的单体架构。通过现有 `httpx` 异步调用 Tavily Search 与 Extract，不新增 SDK、Agent 框架、MCP 服务或浏览器抓取进程。

搜索和正文读取同时交付。搜索摘要只帮助选择来源；正文提取使用 `/extract`、`extract_depth=advanced`、`format=markdown`，不传 `query` 或 `chunks_per_source`，避免请求相关片段而非正文。真实联网验收验证公开 HTTPX 文档的内容质量和长文续读；不以这几个页面推断所有网站的覆盖率。

接口依据：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。Extract 即使 HTTP 200 仍可能只有 `failed_results`，必须检查正文结果。

## 配置与授权

`network_enabled` 默认 false。操作者在 JSON 中设为 true 并通过环境变量或显式 `.env` 提供 `TAVILY_API_KEY` 后，模型可在本次运行预算内自动搜索和读取，不逐条请求审批。CLI 与 Web 使用相同策略；真实 Shell 的逐次审批不变。页面配置说明在开始任务前提示是否启用、是否缺少密钥，以及搜索词和待读网址会发送给 Tavily。

密钥只在后端使用，不进入工具 schema、前端、模型提示或配置快照。Runner 将 Tavily 密钥加入运行存储的脱敏列表；查询及保存正文也应用已有精确值脱敏。此机制不是任意敏感信息识别器。源网页和模型回答是本地运行资料，应按现有运行记录策略保管。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `search_timeout_seconds` | 30 | 一次搜索工具调用的总时限，含重试 |
| `extract_timeout_seconds` | 45 | 一次正文工具调用的总时限，含 DNS、请求、重试 |
| `max_search_requests` | 5 | 每任务最多实际搜索请求数，重试占用 |
| `max_extract_requests` | 10 | 每任务最多实际提取请求数，重试占用 |
| `search_max_results` | 5 | 每次最多结果数，配置允许 1–10 |
| `network_max_response_bytes` | 2097152 | 每个 API 响应解压后最大字节数 |
| `max_web_document_chars` | 200000 | 每份提取正文最多保存字符数 |
| `max_web_storage_chars` | 500000 | 每任务正文累计最多保存字符数 |
| `web_chunk_chars` | 4000 | 单次最多返回正文字符数，仍受序列化输出预算限制 |

联网启用要求 `max_output_chars >= 4096`。工具调用仍计入原有工具次数、轮数与总时长；总时限优先。续读不产生外部请求，但计入工具预算。没有配置结果检查时仍为 `unverified`。

## 工具契约与持久化

`web_search(query, max_results?, time_range?, include_domains?)` 校验查询、数量、时间范围和域名；后端固定 basic 深度、关闭自动参数及服务生成答案。返回 `source_id`、标题、完整网址和短摘要。输出不足时先缩短摘要，再减少返回条目，并标记 `truncated` 和 `omitted`，不截断网址。

`read_webpage` 支持两种互斥参数：

- 首次读取：`{"url":"https://example.com/article","offset":0}`。
- 续读：`{"document_id":"D1","offset":4000,"max_chars":4000}`。

`max_chars` 可省略；首次 offset 必须为零。相同规范化网址在同一任务中重用保存的正文；需要重新抓取可发起新任务。不同任务不会共享缓存，也不支持中断任务自动续跑。

结果包含文档编号、来源编号、原始请求网址、服务返回网址、标题、抓取时间、提取总长度、保存长度、存储截断状态、正文 SHA256、当前范围、`next_offset`、`end_of_saved_body` 和正文片段。位置单位是 Python Unicode 字符索引，不是 UTF-8 字节。`next_offset=null` 只表示本次片段到达保存正文末尾。

每份文档保存在运行目录 `web-D<n>.json`；`sources.json` 保存来源索引、实际请求次数和读取范围。合并已返回片段的区间，只有并集覆盖整个保存正文才记录 `saved_body_fully_read=true`，跳到尾部不算读完。正文超过文档或累计保存上限时明确记录存储截断；API 响应超过字节上限则拒绝整个响应。

完整来源索引每轮重新加入上下文，保留文档编号与已读范围，独立于近期历史裁剪。它仍计入模型输入预算；超过预算时按现有规则明确结束，不静默删除来源。正文片段在进入通用结果截断前适配实际 JSON 序列化长度，保留结构、来源和续读位置。

最终结果附带网络来源清单及 `citation_check`，检查 `[S<n>]` 是否存在，并在页面提示未知编号。该检查不证明引用网址匹配、事实支持、来源可信或网页完整，也不改变检查通过状态。模型应引用实际来源，并披露未读范围和提取限制。

## 执行边界与失败

只向固定的 `https://api.tavily.com/search` 和 `/extract` 发送请求，不跟随 API 重定向，不自行下载目标网页。拒绝非 HTTP(S)、认证信息、非标准端口、控制字符、本机和非公开 IP，以及保留的本地域名。提取前异步解析 DNS，任何非公开地址均拒绝；对服务返回网址也进行检查。

这里的 DNS 检查是客户端预检。实际抓取、目标连接和网页重定向由 Tavily 执行，本地不能固定其解析结果或审计每次跳转，不能宣称完整阻止第三方路径中的 DNS 重绑定或 SSRF。今后如加入自行抓取，须增加连接目标固定和逐跳校验；本阶段没有这样的直连后备通道。

网页正文、标题、链接及搜索结果均为不可信资料，不能改变执行器权限或规范。程序原有文件边界、Shell 审批和取消机制独立执行。提示词用于引导模型，不能作为杜绝所有提示注入的保证。

鉴权失败、额度耗尽和参数错误不重试。限流、选定 5xx、传输错误和网络超时有限退避；每次实际请求在派发前占用预算并落盘。取消可中断异步请求或退避，关闭 HTTP 客户端并停止后续派发，无法撤回远端已处理请求或费用。

空搜索结果属于成功；正文未返回或为空、响应格式错误、超大响应、未知文档、非法偏移和不安全网址分别返回安全错误码，不落盘服务原始错误正文或鉴权头。公开网页提取并不保证原文完整，统一标记 `original_completeness=unknown`。登录、验证码、交互页面及 PDF 不在保证范围内。

## 页面与验收

工作台沿用工具和网络事件显示搜索词、读取网址、错误、重试和耗时。“工具调用”页签显示可点击来源、时间、保存长度、已读范围及完整性说明；详情保留原始元数据。普通轮询不重建未变化的来源卡片，页面刷新从磁盘恢复，不再次执行网络工具。链接限制 HTTP(S)，新窗口链接添加 `noopener noreferrer`，正文及元数据按文本展示。

自动化检查覆盖参数、配置、预算、错误、超时取消、长文连续读取、跳读、截断、恶意链接和权限边界。`python -m tests.live_stage_seven` 通过自有 Web 测试服务调用真实模型与 Tavily，检查实际正文反馈、回答细节、引用、刷新和日志一致性；服务在 finally 中停止并核对进程和端口。
